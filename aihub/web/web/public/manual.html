// 快速上手

3 分钟，从注册到调用

01
注册账号访问 AIHub 首页，点击「注册」，填写用户名、密码和邮箱。
02
创建令牌进入「令牌」页面 → 新建令牌 → 填写名称、设置额度 → 保存并复制 sk-xxx。
03
配置客户端将 API 地址替换为 AIHub 地址，使用生成的令牌作为 API Key。
04
开始调用发送第一个请求到 /v1/chat/completions，在日志页面查看记录。
bash
# OpenAI 兼容协议 — 只需替换 base_url
curl https://your-aihub-host/v1/chat/completions \
  -H "Authorization: Bearer sk-your-token" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o",
    "messages": [{"role": "user", "content": "Hello!"}]
  }'
python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-token",
    base_url="https://your-aihub-host/v1"
)

response = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "Hello!"}]
)
print(response.choices[0].message.content)
javascript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-token',
  baseURL: 'https://your-aihub-host/v1'
});

const res = await client.chat.completions.create({
  model: 'gpt-4o',
  messages: [{ role: 'user', content: 'Hello!' }]
});
console.log(res.choices[0].message.content);

// 令牌管理

创建 API 密钥，精细控制访问

令牌 (Token) 是调用 API 的密钥凭证，以 sk- 开头，可独立设置额度和模型范围。

01
进入令牌页面侧边栏点击「令牌」→ 令牌管理页面
02
新建令牌点击「新建令牌」按钮，填写配置信息
03
配置参数设置名称、额度上限、过期时间、可用模型（均可选）
04
保存并复制创建成功后 立即复制，令牌只在创建时完整显示一次
名称
必填 — 令牌标识名称，方便管理
额度
可选 — 不填则不限制，单位为美元等价
过期
可选 — 不填则永不过期
模型
可选 — 限制可访问的模型列表
子网
可选 — 限制允许访问的 IP / CIDR 网段
使用方式 — OpenAI 协议：替换 api.openai.com，路径 /v1/chat/completions
Anthropic 协议：替换 api.anthropic.com，路径 /v1/messages
指定渠道 — 使用 sk-{token}-{channelId} 格式可固定路由到特定渠道

// MCP 代理平台 · MCP PROXY

MCP 工具统一网关，全链路管理

AIHub 完整支持 MCP (Model Context Protocol) 协议。对接上游供应商工具、内置视觉理解能力， 所有用户可通过 Claude Code、Cursor 等客户端直接调用平台 MCP 工具。

SERVER

MCP 服务端点

Streamable HTTP + SSE 双传输协议。Token 鉴权，按用户绑定会话，兼容主流 MCP 客户端。

PROXY

上游供应商代理

对接 Minimax、智谱等外部 MCP 供应商。工具自动同步，前缀路由转发，断线自动重连。

BUILTIN

内置视觉理解

vision_analyze 工具，复用渠道多模态能力。选择渠道和模型即可使用，无需额外部署。

配置 Claude Code

在 Claude Code 配置文件 .claude/settings.json 中添加 MCP Server：

claude settings — Streamable HTTP
{
  "mcpServers": {
    "aihub": {
      "type": "streamable-http",
      "url": "https://your-aihub-host/mcp/v1/message",
      "headers": {
        "Authorization": "Bearer sk-your-token"
      }
    }
  }
}

// 常见问题

FAQ & 故障排查

Q1支持哪些 AI 模型？
支持 38 个供应商的所有主流模型，包括 OpenAI (GPT-4o, GPT-4, GPT-3.5)、Anthropic (Claude 系列)、 Google Gemini、AWS Bedrock Claude、Azure OpenAI、百度文心、阿里通义、讯飞星火、Moonshot、 Zhipu、Mistral 等。具体可用模型取决于管理员配置的渠道。
Q2令牌创建后无法复制？
令牌密钥仅在创建时完整展示一次。请务必在创建后 立即复制保存。如果丢失，需要删除旧令牌并创建新令牌。
Q3如何指定使用某个渠道？
在模型广场中展开模型详情，点击对应渠道的「复制」按钮，会自动复制 sk-{token}-{channelId} 格式的令牌。 使用此令牌调用 API 时将固定路由到该渠道。
Q4请求返回 401 / 403？
检查令牌是否正确、是否已过期、是否有该模型的访问权限。在令牌管理页面确认令牌状态和配置。
Q5请求返回 "no available channel"？
说明当前没有可用渠道处理该模型。可能原因：渠道被禁用、渠道余额不足、所有渠道故障。联系管理员检查渠道状态。
Q6如何查看费用明细？
在「日志」页面查看每次调用的费用，在「用量报表」页面查看按令牌和渠道维度的汇总统计。
Q7CC Switch 是什么？
CC Switch 是一款 AI API 客户端管理工具。在模型广场点击「CC Switch 导入」按钮，可一键将渠道配置导入客户端。 下载地址：ccswitch.io
Q8如何使用 MCP 功能？
AIHub 内置 MCP Server，支持 Streamable HTTP 和 SSE 两种传输方式。 在 MCP 配置页获取连接地址和令牌，将配置添加到 Claude Code 的 .claude/settings.json 中即可使用。 普通用户可在工具列表页浏览所有可用 MCP 工具。
Q9MCP 内置视觉理解是什么？
平台内置 vision_analyze 工具，复用已配置渠道的多模态模型能力（如 GPT-4o、Claude 等）。 通过 MCP 协议调用时无需额外部署视觉服务。管理员可选择使用哪个渠道和模型来处理视觉请求。
Q10MiniMax 配额显示不正确？
确保平台已更新到最新版本。MiniMax 近期更新了配额 API，新增 remaining_percent 和 remains_time 字段， 旧版平台可能使用已失效的 total_count 字段计算配额。更新后 5h 窗口和周窗口的配额追踪将恢复准确。
